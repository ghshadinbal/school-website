# ಸರಕಾರಿ ಪ್ರೌಢಶಾಲೆ ಹಡಿನಬಾಳ — Super School Website

## Run in VS Code
Open this folder in VS Code and right-click `index.html` → **Open with Live Server**.

## Publish free
Create a GitHub repository, upload all files, then enable GitHub Pages from Settings → Pages → Deploy from branch → `main` → `/ (root)`.

## Before publishing
Replace the placeholder emblem, school photo, staff photos/names, contact details and sample notices/events with official school information.
